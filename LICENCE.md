## 🧩 About

**Dark Souls Hack Menu** is a curated list of Dark Souls open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, state monitor
- **Quality-of-Life Helpers** — item catalog, equipment manager, overlay notes
- **Research Notes** — combat layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- State Switcher — practice from any checkpoint (bonfire)
- Show Hitboxes — visualize enemy and player hitboxes
- Replay Notes — record and review combat runs
- Playback Speed — adjust game speed for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse weapons, armor, rings, consumables
- Custom Skin Notes — organize player cosmetics
- Enhanced Visibility — improved visual clarity for study

### Aimbot
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-level
- Jump Buffer Notes — chain complex maneuvers in the editor
